# KATA RECANVIS — Web corporativa

Proyecto de nueva web informativa de KATA RECANVIS.

## Objetivo
Web corporativa moderna, responsive y accesible para presentar la empresa, sus servicios, marcas y establecimientos. No incluye tienda online, catálogo ni duplicado de llaves.

## Stack previsto
- Laravel
- Blade
- Tailwind CSS
- Alpine.js
- MySQL cuando sea necesario

## Diseño aprobado
- Naranja corporativo del logotipo KATA
- Negro grafito y fondos blancos
- Hero oscuro con fotografía de recambios
- Servicios: recambios, lubricantes y accesorios
- Establecimientos, marcas, contacto y pie de página

## Estado
Repositorio inicializado. Pendiente de generar el esqueleto de Laravel mediante Composer.

> No subir el archivo `.env`, claves ni credenciales al repositorio.
